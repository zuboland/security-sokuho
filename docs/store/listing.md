# Chrome ウェブストア 掲載情報（0.2.0）

## 基本
- 名前：緊急セキュリティ速報
- 概要（132字以内）：悪用が確認された脆弱性であなたのブラウザが影響を受けるとき、大きな情報漏えいが起きたときだけ知らせます。めったに鳴りません。電話やパスワード入力を求めることは一切ありません。
- カテゴリ：ツール（Tools）／言語：日本語
- 公式URL：https://github.com/zuboland/security-sokuho
- プライバシーポリシー：https://zuboland.github.io/security-sokuho/privacy.html
- サポート：https://github.com/zuboland/security-sokuho/issues

## 詳しい説明
緊急地震速報と同じ考え方の、ブラウザ向けのセキュリティ速報です。

■ 何をするか
・悪用が確認された脆弱性（Google／Microsoft／CISA の公式発表）で、あなたのブラウザの版数が修正版より古いときだけ、通知します
・通知をクリックすると「何が起きるか」「今やること」を日本語で1枚にまとめた速報画面が開き、ボタン1つでブラウザの更新画面に進めます
・更新だけでは防げない脅威には、「パスワードを変える」「二段階認証をオンにする」など、あなたにできる守りの行動も示します
・大きな情報漏えい（既定は1,000万件以上・設定で100万件以上／通知しないに変更可）が報じられたら通知し、パスワードの変更など今やることを示します。通知するのは、発表から3日以内で、漏えいが起きたと言い切られ、件数が分かる件だけです。漏えいデータベース由来の件は、1年以内に起きてパスワードかお金の情報を含むものに限ります（すべての漏えいが載るわけではありません）
・SNS で話題になっているだけの未確認の漏えいは、通知せず「未確認」と注意書きを付けて一覧に出します
・アイコンを押すと、直近90日の「悪用が確認された」速報の一覧と、その件について人が書いていること（掲示板・SNS へのリンク）が見られます

■ 判定は3つ
🔴 更新してください／✅ 対応済み・速報なし／⚪ 確認できませんでした
「確認できない」を「大丈夫」とは言いません。分からないときは、手で確かめる手順を出します。

■ 安心のために
・あなたの情報を収集・送信しません。アカウント登録もありません
・外へ出る通信は、公開フィード（静的JSON）の取得だけ。閲覧履歴やページの内容は読みません（tabs 権限・サイトへのアクセス権限を持ちません）
・通知の判定に AI を使いません。修正版の版数は公式データから機械で比べ、漏えいは件数と言い切りの有無で決めます
・この拡張が電話・ダウンロード・支払い・パスワードの入力を求めることはありません。電話番号やダウンロード先を表示する「警告」は、この拡張ではなく詐欺です
・ソースコードは GitHub で公開（MIT）。配信する速報の中身も同じリポジトリで作っています

■ 情報源
脆弱性はブラウザの開発元と公的機関の公開情報、情報漏えいは公開されている漏えいデータベースと報道を使います。一覧はリポジトリの README にあります

## 単一目的（Single purpose）
一般の人に関係する緊急のセキュリティ情報（悪用が確認されたブラウザの脆弱性と、大規模な情報漏えい）を通知し、今やるべき行動を示すこと。

## 権限の理由
- alarms：30分ごとに公開フィードを確認するため
- notifications：ブラウザが影響を受けるとき・大きな情報漏えいが報じられたときだけ通知するため
- storage：判定結果・通知の既読・設定をブラウザ内に保存するため
- リモートコード：使用しない（取得するのはデータ（JSON）だけ。コードは拡張に同梱）

## データの取り扱い（プライバシー申告）
- 収集するデータ：なし（すべての項目を「収集しない」）
- 認定：①ユーザーデータを承認済みの用途以外に使わない ②売却しない ③与信目的で使わない — すべて該当（収集自体が無い）
