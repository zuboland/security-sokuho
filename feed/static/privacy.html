プライバシーポリシー — 緊急セキュリティ速報

最終更新：2026-10-22 ／ 提供者：ZUBOLAND株式会社

要点

  • この拡張は、あなたの情報を収集・送信しません。アカウント登録もありません
  • 外へ出る通信は、公開フィード（静的JSON）の取得だけです。取得先は GitHub Pages（https://zuboland.github.io/security-sokuho/）で、利用者を識別する情報は付けません
  • ブラウザの版数の判定は、すべてあなたのブラウザの中で行います。版数が外に送られることはありません

この拡張が扱う情報

ブラウザの版数あなたのブラウザから読み取り、公開フィードの「修正版の版数」と比べます。ブラウザの中だけで使い、保存は判定結果（要対応／対応不要／判定不能）とあわせて chrome.storage（お使いのブラウザ内）に置きます
通知の既読同じ速報を2回鳴らさないために、鳴らした速報の ID をブラウザ内に保存します
設定配信元URL・通知のオン／オフ。ブラウザの同期ストレージ（chrome.storage.sync）に保存され、あなたの Google アカウントで同期されることがあります。この拡張の提供者には届きません

収集しない情報

閲覧履歴・開いているページの内容・入力した文字・Cookie・個人を特定できる情報は、読み取りも送信もしません。この拡張は tabs 権限や host_permissions（サイトへのアクセス権限）を持ちません。

使う権限とその理由

alarms30分ごとに公開フィードを確認するため
notifications悪用が確認された脆弱性で、あなたのブラウザが影響を受けるときだけ通知するため
storage判定結果・既読・設定をブラウザ内に保存するため

外部サービスへのリンク

速報の一覧には、一次情報（Google・Microsoft・CISA・JPCERT/CC・IPA）や、関連する投稿（Hacker News・X）へのリンクが含まれます。リンクを開いたあとの取り扱いは、それぞれのサービスのポリシーに従います。この拡張がそれらのサービスにあなたの情報を送ることはありません。

この速報が求めないこと

この拡張が電話・ダウンロード・支払いを求めることはありません。電話番号やダウンロード先を表示する「警告」は、この拡張ではなく詐欺です。

変更・お問い合わせ

このポリシーを変えるときは、このページで知らせます。ソースコードは GitHub で公開しています。お問い合わせは GitHub の Issues へどうぞ。
