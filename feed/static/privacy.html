プライバシーポリシー — 緊急セキュリティ速報

最終更新：2026-10-27 ／ 提供者：ZUBOLAND株式会社

要点

  • この拡張は、あなたの情報を収集・送信しません。アカウント登録もありません
  • 外へ出る通信は、公開フィード（静的JSON）の取得だけです。取得先は GitHub Pages（https://zuboland.github.io/security-sokuho/）で、利用者を識別する情報は付けません
  • ブラウザの版数の判定は、すべてあなたのブラウザの中で行います。版数が外に送られることはありません

この拡張が扱う情報

ブラウザの版数あなたのブラウザから読み取り、公開フィードの「修正版の版数」と比べます。ブラウザの中だけで使い、保存は判定結果（要対応／対応不要／判定不能）とあわせて chrome.storage（お使いのブラウザ内）に置きます
通知の既読同じ速報を2回鳴らさないために、鳴らした速報の ID をブラウザ内に保存します
設定配信元URL・通知のオン／オフ・情報漏えいを通知する大きさ（1,000万件以上／100万件以上／通知しない）。ブラウザの同期ストレージ（chrome.storage.sync）に保存され、あなたの Google アカウントで同期されることがあります。この拡張の提供者には届きません

収集しない情報

閲覧履歴・開いているページの内容・入力した文字・Cookie・個人を特定できる情報は、読み取りも送信もしません。この拡張は tabs 権限や host_permissions（サイトへのアクセス権限）を持ちません。

使う権限とその理由

alarms30分ごとに公開フィードを確認するため
notifications悪用が確認された脆弱性で、あなたのブラウザが影響を受けるとき、および大きな情報漏えいが報じられたときだけ通知するため
storage判定結果・既読・設定をブラウザ内に保存するため

常駐アプリ（Windows）について

常駐アプリも同じ方針です。PC に入っているソフトの一覧（winget list・レジストリの表示名と版数・Windows のビルド番号）はPC の中だけで公開フィードと比べ、このアプリが外へ送ることはありません。判定結果・通知の既読・設定はアプリのデータ領域（WebView2）に保存され、アンインストール時に Windows の仕組みに従って扱われます。

winget について（正直に書きます）。常駐アプリは起動時と6時間ごとの確認で Windows の winget list を実行します。winget は Microsoft のパッケージ管理ツールで、一覧を作るときにソース（Microsoft の winget／msstore）へ照会し、更新を押したときは配布元から取得します。また winget 自体は Windows の診断データ設定に従って利用状況を Microsoft に送ることがあります（winget の説明）。このアプリはその設定を変えませんし、読みもしません。「winget を一切動かしたくない」場合は、このアプリを使わないでください。

公開フィードの配信元について。フィードは GitHub Pages で配信しています。このアプリ・拡張は利用者を識別する情報を付けませんが、GitHub は通信に伴うアクセス元の IP アドレス等を自社のポリシーに従って保存することがあります（GitHub の説明）。これは私たち（ZUBOLAND）には届きません。

外部サービスへのリンク

速報の一覧には、一次情報（Google・Microsoft・CISA・JPCERT/CC・IPA）や、関連する投稿（Hacker News・X）へのリンクが含まれます。情報漏えいの一覧には、報道（ScanNetSecurity・Security NEXT）と Have I Been Pwned の該当ページ、X の検索結果へのリンクが含まれます（X で話題の件は未確認として表示し、通知しません）。リンクを開いたあとの取り扱いは、それぞれのサービスのポリシーに従います。この拡張がそれらのサービスにあなたの情報を送ることはありません。

この速報が求めないこと

この拡張が電話・ダウンロード・支払い・パスワードの入力を求めることはありません。電話番号やダウンロード先を表示する「警告」は、この拡張ではなく詐欺です。
